**Philobiblos, what to read next.** A self-hosted app that decides what to read next so that a person's knowledge grows
in breadth and depth, and turns that into a monthly book order within a family budget. It runs as a HomersLab app or
standalone with `docker compose up`.

Start with [HANDOFF.md](HANDOFF.md), then [docs/spec.md](docs/spec.md) and [docs/adr/](docs/adr/). The logo and how to
use it: [docs/brand/](docs/brand/GUIDELINES.md).
